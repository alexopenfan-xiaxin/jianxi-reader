## v3.0.0 更新详情

3.0 把简兮从「能读 Markdown」推进到「能管一个本地知识库」：导入、搜索、痕迹、撤销都在，数据仍然只留在本机。

### 🚀 新功能

- **文件夹按包导入** — 选择文件夹时整包复制，保留目录结构，图片、CSS、附件一并带入，相对链接可用。
- **阅读痕迹** — 新增「阅读痕迹」页，书签与阅读历史集中管理，可跳转、可删除；书签与标签共用同一份元数据。
- **全文搜索** — 文档库支持「标题 / 全文」两种范围，全文结果带上下文片段，点进去直接高亮命中。
- **删除可撤销** — 单个与批量移出都有 10 秒撤销窗口，文件先进回收区，24 小时后清理。

### ⚡ 体验优化

- **元数据 schema v1** — 迁移前自动备份；单条损坏只丢那一条并隔离原文件；升级后标签、书签、阅读进度都不丢。
- **更新更可信** — 缺签名凭证时构建直接失败；APK 附 SHA256SUMS；能拿到摘要就校验，拿不到仍会安装，交由 Android 自身的签名校验兜底。
- **体积** — 内置字体子集化，APK 从 37 MB 降到 26.8 MB。
- **可访问性** — 正文灰色达到 WCAG AA；系统字号限制在 1.0–1.6 防溢出；尊重「移除动画」。

### 🐛 问题修复

- **发丝线** — 卡片、输入框、分隔线的边框改为 1 物理像素并跟随屏幕密度，不再是 3 倍屏上的粗灰边。
- **边缘羽化** — 首页与设置页的列表从悬浮顶栏下方渐隐淡出，不再是硬切口；滚到顶 / 底时羽化自动收起。
- **大字号** — 顶栏标题不再随系统字号放大而挤出玻璃条，列表起始位置改按顶栏高度推导。
- **深色模式** — 标题字重下调一档，避免浅色文字在深底上发胀。
- **中文输入** — 拼音还停在候选框里时不再触发搜索，不会闪一下「没有结果」；开启「移除动画」后按压回弹一并关闭。

### 🔧 其他

- 版本更新为 `3.0.0+300`，应用内 fallback build number 同步为 300。
- 数据只保存在本机：卸载或换手机会一并丢失，请自行保留源笔记。
- Android 上的文件夹导入仍为逐文件复制（不保留目录结构），后续版本再补。
